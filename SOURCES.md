# DHO source notes

- Official repository: https://github.com/erjui/DHO
- Paper version used: https://arxiv.org/html/2505.07675v2
- Full PDF read: https://arxiv.org/pdf/2505.07675v2
- Revision date: 2026-10-04
- Release status: Code available in the official repository.

The page summarizes the main paper and relevant supplemental analyses. Tables and
figures identify their paper numbers beside the content. Research figures are original
paper assets or crops of the original PDF and remain attributable to the authors.
Prose is an editorial summary, not a verbatim abstract. Policy walkthroughs are scripted
illustrations, not live model outputs. No conference acceptance is implied.

This directory is a standalone static site. Build from the parent directory with
`python3 build.py`. Metadata is in projects.json and narratives in content.py.
